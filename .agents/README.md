# Personal agent reference bundle

[AGENTS.md](AGENTS.md) preserves my working guidelines, including YAGNI, type safety, focused tests, understanding the feature first, and treating questions as read-only. [skills/](skills/README.md) contains my reusable skills and the original HTML-output version for reference.

This folder is a reference bundle for moving between devices. Copy the selected files into the global or project-specific locations supported by the target harness. The folder structure here is for storage; it does not imply automatic installation.

Use the current html-output skill when installing. The html-output-original folder is an archive and retains the same skill name; do not install both as active skills.

Example request for an agent on a new device:

> Read https://github.com/ManishModak/ManishModak/tree/main/.agents and install the current skills and my AGENTS.md guidelines globally for [harness name] on this device. Check that harness's supported locations, preserve unrelated existing instructions, and flag conflicting preferences before overwriting them. Exclude html-output-original from installation.
